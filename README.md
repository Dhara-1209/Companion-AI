## 🔧 Quick Start

### ⚡ **One-Minute Setup**
```bash
# Clone and run
git clone https://github.com/your-username/companion-ai.git
cd companion-ai
pip install -r requirements.txt

# Start servers
python -m uvicorn src.backend.main:app --host 127.0.0.1 --port 8000 &
streamlit run src/frontend/app.py --server.port 8501

# Open: http://localhost:8501
```

### 🎯 **Try These Examples**
```bash
# Test the AI with these queries:
"My Samsung washing machine shows E3 error code"
"Dishwasher not cleaning dishes properly"
"I smell gas from my oven"
"Microwave turntable not spinning"
```
