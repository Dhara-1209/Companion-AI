# 🏠 HomeBuddy: Your Smart Companion for Every Home Appliance

**AI-powered assistant that helps you troubleshoot, maintain, and manage your home appliances.**

## 🎯 What is HomeBuddy?

HomeBuddy is an intelligent home management system that provides instant appliance troubleshooting, predictive maintenance alerts, and comprehensive repair tracking—saving you time and money on unnecessary service calls.

## ✨ Key Features

- **🤖 AI Diagnosis** - Natural language troubleshooting with instant solutions
- **📱 Appliance Tracking** - Monitor all your home devices in one place
- **🔧 Repair History** - Track maintenance costs and identify recurring issues
- **⏰ Smart Alerts** - Predictive maintenance reminders and warranty tracking
- **🛡️ Safety First** - Emergency detection with 4-level safety protocols
- **📚 Comprehensive Database** - 15+ brands, 40+ error codes, 500+ manual pages

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Hetvi2211/Homebuddy.git
cd Homebuddy

# Install dependencies
npm install --legacy-peer-deps
pip install -r requirements.txt

# Run frontend (http://localhost:5173)
npm run dev

# Run backend (http://localhost:8000)
python src/backend/main.py
```

## 🛠️ Tech Stack

**Frontend:** React 18.3, TypeScript 5, Vite, Tailwind CSS, Material-UI  
**Backend:** FastAPI, Python 3.11  
**AI:** RAG Pipeline, Vector Search, NLP
