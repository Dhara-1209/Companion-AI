## 🚀 Project Features

### Feature 1: Track Appliances ✅
- Add multiple appliances (5 types supported)
- Store detailed appliance information
- Auto-generate maintenance tasks
- Display with status indicators

### Feature 2: Repair History ✅
- Log complete repair details
- Track DIY vs. professional repairs
- Calculate repair statistics
- Identify recurring issues

### Feature 3: Predictive Maintenance ✅
- Schedule maintenance at specific intervals (6 months for lint cleaning)
- Generate alerts for overdue tasks
- Warranty expiry warnings
- Recurring issue detection
